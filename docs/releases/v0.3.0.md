# Sion Ontology Platform v0.3.0 — release notes (draft)

Status: **release preparation**. This document is a draft for the v0.3.0 release; the release PR
adds the version bump, changelog and these notes. **No git tag, GitHub release or package
publication is created by this change.** Tagging is a separate, explicit maintainer step.

## Highlights

- **One installable package set.** Regulation, AEC/Ontology and GOD-CAD ship as `packages/` inside
  the monorepo (`sion-ontology-platform` with `cad`, `bim`, `rag`, `drive`, `regulation`,
  `documents` and `validation` extras). ArchOntos is a pinned dependency of the `regulation` extra
  rather than a vendored copy.
- **EmbedHub.** Pluggable multi-model embedding framework (NVIDIA endpoint key pool, reciprocal
  rank fusion, real-drawing benchmark) now backs GraphRAG retrieval.
- **AEC consolidation phase 1.** Ontology drawings are ingested into the Sion graph/evidence store
  through `aec-cair-snapshot/1`, with read-only bridge boundaries and idempotent imports.
- **Regulation workspace.** Project review storage, source-cited briefings, MCP router bridge and
  the `building-regulation-report/1` contract; regulation failures fail closed.
- **Law knowledge (slice 1).** Canonical law-article store with `as_of` search.
- **Review workflow.** Bulk decision API, faster `/review` UI, per-item results, rejected-state
  handling and review-state-aware GraphRAG projection.
- **Operational hardening.** One-command switch to `packages/aec`, in-container backup/restore,
  graceful worker drain, non-interruptible watchdog tasks and a read-only readiness preflight.

## Upgrade notes

- Project version is **0.3.0** in `pyproject.toml`; the API reports the same value from
  `apps/api/sion_api/__init__.py` (`__version__`, exposed by the health endpoint).
- `uv.lock` was regenerated for the version bump. No dependency versions changed in this release
  preparation.
- Install extras explicitly, for example:
  - `pip install -e ".[all,test,dev]"` for a full development checkout,
  - `pip install 'sion-ontology-platform[regulation]'` for regulation/ArchOntos work,
  - `pip install -e ".[aec]"` for the AEC stack.
- ArchOntos is consumed as a pinned dependency. Do not copy `archontos/` under `packages/`; change
  ArchOntos in its own repository and bump the pin.
- HS-CAD is retired. Do not add HS-CAD contracts, fixtures or work items.
- Existing database migrations are unchanged by this release; run the normal migration entry point
  after upgrading.
