## 4. 그룹#105 (카페 가구 FF&E) 재구성

[정정] 이전 판은 그룹#105를 별동으로 잘못 봤습니다. 그룹#105는 본동 1층 바닥(FL+5000)과 평면이 겹치는 카페 가구 묶음이고, 별동은 그룹#217입니다.

[관측] `그룹#105 > 그룹#160` 한 겹 래퍼 아래 자식이 모여 있고, 반복 컴포넌트가 많습니다: `C1` 의자 ×47, `T` ×8, `SO` ×8, `T2` ×5.

- 래퍼 `그룹#160`을 분해해 깊이를 한 단계 줄이고, 그룹#105 이름을 `INT-1F-카페가구`, 태그를 `@FUR`로 바꿉니다.
- Z 4847–10200 → 본동 1층(FL+5000) 가구. 건물 외피·바닥은 이 그룹에 넣지 않습니다.
- 가구 컴포넌트 이름: `C1` → `CH-C1`, `T` → `TB-T`, `T2` → `TB-T2`, `SO` → `SF-SO` (규격은 bbox 확인 후 `CH-450x460x741`처럼 확정). 정의만 바꾸면 인스턴스 전체에 반영됩니다.

## 10. 실행 순서와 검증

1. SketchUp에서 원본을 `0914_담당미팅_원본.skp`로 따로 저장.
