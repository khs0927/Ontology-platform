# 26. Hueflow + sketchup-mcp2 동시구동 지침 (2026-10-27)

목적: SketchUp 한 인스턴스에 **sketchup-mcp2(MCPforSketchUp)** 와 **Hueflow** 두 MCP 플러그인을 동시에 켜 두고, 포트·단위·쓰기 충돌 없이 쓰기 위한 정본 규칙.
대상 PC: 사용자 프로필 `C:\Users\USER` (구계정 khs09 경로는 쓰지 않는다).

## 1. 포트 (동시 Listen 정상·권장)
| 서버 | 플러그인 | 주소 | 프로토콜 |
|---|---|---|---|
| sketchup-mcp2 | MCPforSketchUp | 127.0.0.1:9876 | TCP |
| hueflow | Hueflow SketchUp | 127.0.0.1:8080 | HTTP |
| (참고) QGIS | qgis_mcp | 9877 | - |
- 9876과 8080이 **같이 Listen 하는 상태가 정상**이다. 한쪽만 떠 있으면 다른 쪽 서버를 시작한다.
- Blender 등 다른 앱은 9876을 쓰지 않는다(Blender는 9877 이외 포트로 분리, QGIS와도 겹치지 않게).
- `SKETCHUP_MCP_PORT`는 플러그인 접속 주소다. 바꾸면 끊긴다.

## 2. 역할 분담
- **주 경로 = sketchup-mcp2**: 작도, 엔티티 검색, undo, 뷰포트/카메라, 내보내기.
- **보조·폴백 = Hueflow**: 면·모서리·호·push_pull 등 기본형 보완, mcp2에 없는 도구, mcp2 장애 시 폴백.
- Hueflow가 먼저 응답하거나 먼저 살아 있어도 **주 도구를 Hueflow로 바꾸지 않는다**(사용자 보존 지시).

## 3. 단위
- mcp2: 항상 **mm**.
- Hueflow: **모델 단위**(inch일 수 있음). Hueflow로 쓰기 전 `get_model_info`로 단위를 확인한다.
- 같은 작업 세션에서 두 서버의 좌표를 섞지 않는다. 섞어야 하면 한쪽 단위로 환산해 명시한다.

## 4. 쓰기 규칙
- SketchUp Ruby는 사실상 단일 UI 스레드다. **두 MCP에서 동시에 형상 변경(eval_ruby / execute_ruby / 작도 도구) 호출 금지.** 한 번에 한 서버, 한 호출씩 직렬로.
- 읽기(조회·get_model_info·검색)는 병렬 가능.
- 큰 작업 전 저장. 면 1.5만 개 넘는 모델은 어느 서버든 멈출 수 있다.

## 5. 기동·고정
- mcp2: `mcp_for_sketchup_autostart.rb`가 SketchUp 시작 시 확장 require + `Application.start`. 로그 `%TEMP%\mcp2-autostart.log`.
- PrivatePreferences의 `mcp_for_sketchup.rb` 확장 활성값은 **1 유지**. 0이면 메뉴/상수 미로드(NameError).
- Hueflow: 자동시작이 없으면 확장 메뉴에서 **Start** 해야 8080이 뜬다.
- 확장 로딩 정책 HARD ERROR 시 Identified/Unrestricted로.
- Plugins 폴더는 junction `D:\C_Drive_Offload\SketchUp2025_Plugins`.
- 클라이언트 whl: `sketchup_mcp2-0.4.0` 권장, `UV_CACHE_DIR=C:\Users\USER\.cache\uv-sketchup-mcp2`. hueflow는 `uvx hueflow-sketchup-mcp`.
- 여러 에이전트/앱이 같은 sketchup-mcp2 정의로 각자 stdio 프로세스를 띄워도 된다. 충돌 지점은 플러그인 TCP 포트와 동시 쓰기뿐.

## 6. 장애
| 증상 | 원인 | 대응 |
|---|---|---|
| 8080이 accept만 하고 응답 없음 | Hueflow 서버 hang → Ruby 타이머 정지 | mcp2 autostart/서버도 같이 먹통 가능. 도면 저장 후 SketchUp 재시작(강제종료 금지, 사용자 확인) |
| mcp2 메뉴 없음/NameError | PrivatePreferences `mcp_for_sketchup.rb`=0 | 1로 되돌리고 재시작, 또는 Ruby Console에서 require + start |
| 9876 미Listen | autostart 실패 | `%TEMP%\mcp2-autostart.log` 확인, Ruby Console 수동 기동 |
| 좌표가 25.4배 어긋남 | mm/inch 혼용 | 3절 단위 규칙 |
| 결과 꼬임/undo 깨짐 | 동시 쓰기 | 4절 직렬화 |

## 7. 검증
```powershell
Get-NetTCPConnection -LocalPort 9876,8080 -State Listen
cd C:\Users\USER\grokbot-mcp-bridge
node cad-check.cjs                      # sketchup-mcp2, hueflow 포함 PASS
node mcp-call.mjs call sketchup-mcp2 get_version --args '{}'   # compatible true
node mcp-call.mjs call hueflow get_model_info --args '{}'      # 단위 확인
```
