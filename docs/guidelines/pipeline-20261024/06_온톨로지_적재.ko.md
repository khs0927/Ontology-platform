# 06. 온톨로지 적재(Ontology-platform)

## 수집기
`scripts/ontology/collect_zium_law.py` — 원천 파일만 읽어 `sion-map-export/v1` 그래프와 JSON-LD를 만든다(값 생성 없음, 키 이름에 key/token/secret 등이 있으면 버림).
- 지음 기준: `standards/zium/manifest.json` 항목 → Document(found) / Concept(gap), `PART_OF standard:zium`
- 법규·대지 결과: `site-calls-*/*.out.json` → Dataset, `Tool PRODUCES Dataset`, `REFERENCES project:goyeon-1525`; 주요 값은 `finding:*` Concept(EXTRACTED_FROM 결과)
- 산출물: `C:\CODE\zium-templates` dwt/skp/rte/rfa/ifc/rvt/dwg → Deliverable(sha256), 템플릿 `IMPLEMENTS standard:zium`, 스모크 skp→ifc→rvt `DERIVED_FROM`, sheet.dwg `USES` dwt

```powershell
python scripts/ontology/collect_zium_law.py --out runtime/ontology/zium_law_20261024
# DB(포트 55432) 적재
$env:SION_DATABASE_URL = (doppler secrets get ... --plain)   # 값은 화면에 찍지 않는다
python scripts/ontology/ingest_map.py runtime/ontology/zium_law_20261024.map.json
```
또는 API `POST /api/v1/import/...`(map import) 사용. GraphRAG는 `POST /api/v1/graphrag/project` 후 `POST /api/v1/graphrag/query` (`docs/GRAPHRAG.md`).
