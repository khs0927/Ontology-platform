# 04. 알려진 문제

| 문제 | 영향 | 대응 |
|---|---|---|
| SketchUp 면 1.5만 개 초과 시 MCP 호출 멈춤 | 큰 지형/컨텍스트 모델 작업 불가 | 매스·단순화 모델로 작업, 지형은 LandXML로 따로 |
| data.go.kr 실거래가(RTMS) 미승인 | realestate-rtms 호출 실패 "등록되지 않은 서비스키" | Doppler의 data.go.kr 키 5개 모두 RTMS 미신청 → data.go.kr에서 활용신청 필요(사용자) |
| archhub `building_profile` 타임아웃 | 원격 서버(mcp.gomdori.app)의 data.go.kr 호출 30초 초과 | site-pipeline `building_register`로 대체 |
| 일부 설정 파일에 평문 키 | 유출 위험 | doppler 래핑으로 바꾸고 키 회전. 저장소·드라이브에 설정 파일 올리지 말 것 |
| horizun-revit health 30초+ 무응답 | 가끔 미검증 | rvt-mcp 사용 |
| power-cad 새 도면/열기 명령 없음 | 열린 도면 없으면 그릴 수 없음 | AutoCAD에서 도면 열기 또는 ezdxf+ODA |
| osm find_nearby_places 406 | 원본 버그 | 패치본(`_vendor\osm-mcp-server-patched`) 사용 |
| blender 기본 포트 9876 충돌 | sketchup-mcp2와 충돌 | 9877 |
| 작업 스케줄러 logon 등록 거부 | 관리자 권한 필요 | 시작프로그램 바로가기 |
| V-World 해외 IP 차단 | 클라우드에서 호출 불가 | PC에서만 호출 |
| DEM 해상도(GLO-30, ~28m) | 설계용 아님 | 국토지리정보원 5m DEM/수치지형도 사용 |
| C: 디스크 부족(ENOSPC) | Revit 스크립트 실패, PC 멈춤·연결 끊김, Google Drive for desktop 종료, Docker 기동 실패 | 여유 공간 확보 후 재시작 |
