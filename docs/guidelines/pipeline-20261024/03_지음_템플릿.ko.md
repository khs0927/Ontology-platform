## 남은 수동 작업 (2026-10-28 기준, API로 불가하거나 원본 없음)
1. 축척별 선 두께표: 관리 → 추가 설정 → 선 두께 (UI 1회). Revit API에 선 두께표 설정 기능 없음. 값 원본(축척별 mm)도 아직 없음.
2. 라벨 접두/추가: 레벨값 `(G.L+…)` 접두, 뷰제목 시트번호 라벨 추가, 도곽 라벨 — 패밀리 편집기 UI. API는 `AnnotationLabelParameterFormatting`의 Prefix를 읽기만 가능(설정자 없음), 라벨 생성 API 없음. (타입 분리는 완료)
3. 단면 헤드 시트번호/참조 라벨 배치, 단면 테일: 원본에 기호 없음 → 기본값 유지.
4. CTB 플롯 스타일: 원본 없음(드라이브·PC 검색 결과 없음).
5. 프로젝트별 값(단열표, 층고, SIN36_3x 필터)은 템플릿 범위 밖.

주의: Revit이 `ZIUM_template_v2.rte`를 열고 있는 동안 다른 프로세스로 수정하지 말 것(파일 복사는 가능).
