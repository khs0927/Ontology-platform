## Revit v2 내용
- 문자 18종(TextNoteType, 나눔고딕, 배경 투명, 폭 1.0). NanumSquare 미설치 → 나눔고딕 대체.
- 치수 3종: 3mm, 3mm 상세(SIN36, 문자 2.5·사선 틱), `ZIUM 치수 80`(문자 2).
- 선 스타일 15종(Lines 하위), `ZIUM_숨은선` 2/1mm.
- 객체 스타일 SIN36 펜 위계: 구조체 절단 6/투영 2, 계단·문·창 절단 4, 가구·위생 1 회색128, 지형 절단 8, 그리드/레벨 빨강.
- 채워진 영역 7종: 콘크리트 SOLID160, 지중, STO 모래, 유리난간, 슬래브단부, 소방관진입창(빨강), KEY PLAN.
- 뷰 템플릿 6종: Z-평면 1/60, Z-배치 1/300, Z-KEY PLAN 1/800, Z-상세 1/30, Z-입면 1/100, Z-단면 1/100.
- 시트 12장(A000~A501, ZIUM_도곽_A1), 뷰포트 `ZIUM 제목 없음`/`ZIUM 뷰제목`.
- DWG 내보내기 `ZIUM_DWG` 217개 레이어(R2018, mm).
- GridType `ZIUM 그리드`, LevelType `ZIUM 레벨` 지정.
- 빌드 스크립트: `scripts/standards/zium_templates/revit_v2/00~45_*.cs` (rvt-mcp `revit_send_code_to_revit`로 실행, 새 템플릿 문서에서만).

## 남은 수동 작업 (API로 불가하거나 원본 없음)
1. 축척별 선 두께표: 관리 → 추가 설정 → 선 두께 (UI 1회).
2. 라벨 형식: 레벨값 `(G.L+…)` 접두, 뷰제목 시트번호 라벨, 도곽 라벨 — 패밀리 편집기에서. 같은 라벨 타입을 공유하는 항목(레벨 이름/값, 뷰제목 이름/번호, 실명/면적)은 타입 분리 필요.
3. 단면 헤드 / KEY PLAN 기호: 원본 블록 DWG가 이 PC에 없음.
4. 해치 근사: AR-SAND, AR-RROOF, NET은 근사 패턴.
5. CTB 플롯 스타일: 원본 없음.
6. 프로젝트별 값(단열표, 층고, SIN36_3x 필터)은 템플릿 범위 밖.

주의: 다른 작업자가 `ZIUM_template_v2.rte` 폰트를 수정 중일 수 있다 — 동시에 열지 말 것.
